Engineered for surgical precision.


      

        
        

          
01

          

            
Anchor-Aware Context Routing

            

              Injecting every rule into every prompt wastes your context window and confuses the model.
              agent-mem hashes target paths and directory basenames, serving only the exact gotchas and conventions linked to the files the agent is actually modifying.
            

          

          

            
# Query relevant memory for a single file

            
agent-mem context --anchor src/store/mod.rs

            

            
# Retrieved in 0.04ms:

            
✓ arch/db (src/store/mod.rs:45)

            
✓ gotcha/wal (src/store/mod.rs:112)

            
Saved: 9,915 tokens from prompt

          

        


        
        

          
02

          

            
Zero Daemons, SQLite WAL in Rust

            

              No Node.js background services, no Docker containers, no external vector services.
              agent-mem runs as a single static binary in native Rust with embedded SQLite in WAL mode and FTS5 BM25 full-text indexing. Sub-millisecond reads from cold start.
            

          

          

            
# Benchmarked on macOS M-series:

            
Point key lookup:  0.038 ms

            
BM25 search (FTS5): 0.120 ms

            
Batch write (20 rules): 1.840 ms

            
Cold start overhead:   < 1.200 ms

          

        


        
        

          
03

          

            
Conflict-Free Git Team Sync

            

              Committing binary SQLite databases to git branches causes corrupted merge conflicts.
              agent-mem mirrors its database into human-readable, reviewable plain text in .agent-rules with an automated merge=union git driver.
            

          

          

            
# Reviewable plain text git diff:

            
+ [rule] arch/concurrency

            
+ Always use atomic transactions

            
+ anchor: src/store/mod.rs

            
merge=union · 0 binary collisions
