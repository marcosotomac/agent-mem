# Security Policy

## Supported Versions

Only the latest release of `agent-mem` receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.3.x   | :white_check_mark: |
| < 1.3.0 | :x:                |

The trust boundaries, prompt-injection risks, resource limits, and release
verification controls are documented in [THREAT_MODEL.md](THREAT_MODEL.md).

## Reporting a Vulnerability

If you discover a security vulnerability in `agent-mem`, please do **not** open a public GitHub issue.

Instead, please report vulnerabilities by opening a private draft advisory under the [Security Advisories](https://github.com/marcosotomac/agent-mem/security/advisories/new) tab on GitHub, or send an email to `158858927+marcosotomac@users.noreply.github.com`.

We take security seriously and will investigate, resolve, and issue patch releases promptly.
